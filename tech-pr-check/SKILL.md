# エンジニア広報の文章確認

受け取った文章を次の4点で確認する。スクリーンショットも対象とし、判読できない文字や画像から分からないリンク先は推測で補わず、必要な箇所だけ原文やURLを求める。

- **誤字**：typo、脱字、固有名詞や技術用語の表記ミス。
- **事実関係**：技術的な説明、人物・所属、日時・曜日、会場、数値などを、提供資料や現在の公式情報と照合する。
- **メンション**：対象サービスのプロフィールや公式サイトから、ハンドルが意図した人物・組織のものか確認する。表示名の一致だけで判断しない。
- **リンク**：実際に開き、到達できるかと、本文で紹介しているページ・イベント・申込先かを確認する。リダイレクト後の宛先も見る。

根拠を確認できない内容は「未確認」とし、誤りや問題なしとは断定しない。アクセス制限による取得失敗もリンク切れと決めつけない。未公開の文章全体や機密情報を外部検索に送らない。

結果は日本語で短く返す。修正が必要な箇所を「原文 → 修正案」と理由で示し、事実・メンション・リンクの指摘には確認した根拠URLを添える。未確認の点は別に示す。問題が見つからなければ「確認した範囲では問題ありません」と伝える。

好みの言い換えや全文の書き直しは、求められた場合だけ行う。投稿・送信は行わない。
